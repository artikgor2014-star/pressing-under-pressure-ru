# Pressing Under Pressure — русская версия

Неофициальный русификатор браузерной игры
[Pressing Under Pressure](https://donitz.itch.io/pressing-under-pressure) от Donitz.
Игра бесплатная, оригинал живёт на itch.io; здесь — тот же билд с переведённым текстом.

**Играть:** https://artikgor2014-star.github.io/pressing-under-pressure-ru/

## Что переведено

- все 43 задания и 7 сообщений экрана проигрыша;
- финальная последовательность (`ВОЗНЕСЕНИЕ` → `ТЫ МОЛОДЕЦ!` → `ОТКЛЮЧЕНИЕ`) и экран `КОНЕЦ`;
- подсказки `ОТПУСТИ` / `СТОЙ!`, счётчики с правильным падежом (`ОСТАЛОСЬ 1 НАЖАТИЕ` / `2 НАЖАТИЯ` / `5 НАЖАТИЙ`);
- интерфейс: загрузка, кнопка `ТИТРЫ`, сами титры;
- заголовок на щите: `ЖМИ / ПОД ДАВЛЕНИЕМ` — перерисован в спрайтах тем же приёмом (вырез в белой маске), что и оригинал.

Шрифт заменён на **Golos Text SemiBold**: в оригинальном Recursive кириллицы нет.
Длинные строки автоматически ужимаются по ширине плиты, поэтому текст не вылезает за кнопку.

## Устройство

Сайт — статика, GitHub Pages отдаёт её из корня ветки `main`.

| Путь | Что это |
|---|---|
| `index.html`, `js/`, `css/`, `images/`, `models/`, `sounds/`, `fonts/` | собранная игра |
| `source/patch/` | изменённые файлы игры относительно оригинала |
| `source/build.py`, `source/title_ru.py`, `source/make_icon.py` | скрипты сборки: наложение патча, шрифт, заголовок, иконки |
| `source/play.bat` | локальный запуск через http-сервер |

Перевод лежит в `source/patch/js/resources/lang.js`: ключ — исходная английская строка.

## Пересборка

```
python source/build.py
```

Скрипту нужна чистая копия билда itch.io в `tools/original/` рядом с `source/`
(скачивается со страницы игры), зависимости — `pillow`, `numpy`, `scipy`, `fonttools`.

## Права

Код и ассеты игры принадлежат Donitz. Тексты перевода можно забирать свободно.
Если автор попросит убрать зеркало — оно будет снято.
